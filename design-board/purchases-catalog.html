· SKU / barcode (qidiruv)
· Oxirgi xarid narxi (price-history)

Tavsiyalar
1. Katalogda asosiy yozuv = Variant (SKU).

2. Tab bilan ajratish: Variantlar (partiya) / Namunalar (serial). Aralashtirmaslik.

3. List default — oxirgi xarid + qoldiq ko‘rinadi. Grid — tez skaner.

4. Topilmasa → C2 bitta sheet: Product+Variant+xarid bir CTA. Serial rejim tanlansa — serial maydonlari ochiladi; instance API confirm da yaratiladi.

5. Agar mahsulot bor, variant yo‘q → faqat «Yangi variant» (productId oldindan).

6. Mavjud web: create alohida sahifa — mobil uchun inline sheet tezroq.
